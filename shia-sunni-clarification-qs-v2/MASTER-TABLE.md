# Master Table — v2

One row per research question, sortable by rank. This is the v2 companion to the per-chapter files in [`chapters/`](chapters/) and the priority board in [`TRACKER.md`](TRACKER.md) — same 25 questions, same underlying data, presented as a single flat table so it can be scanned, sorted, or dropped into a spreadsheet in one piece. A machine-readable copy of the same table is at [`MASTER-TABLE.csv`](MASTER-TABLE.csv) (import it into Excel/Sheets to sort/filter by any column).

**Columns:** *Overall Rank* = position across all 25 questions, ranked by priority tier then chapter order (see `TRACKER.md` for the rationale). *Ch. Rank* = position within that question's own chapter only. *Image Reference(s)* links to the original screenshot in `source/images/` — per the v2 editing permission, the image's text is transcribed in the chapter/answer files rather than the image being re-embedded here; open the image only if you want to see the original pixels. *Reference Sources & Links* lists every named collection/book and every URL already identified in that question's chapter section — generated mechanically from the chapter text (not retyped by hand) so it can't silently drift out of sync; a row reading "none cited yet" means the question doesn't have a source in-text yet and is an open research target, not that no evidence exists.
