# TRACKER — Master Research Board

A single cross-chapter view of every research question in this project, ranked by priority, for deciding what to work next. Each chapter file also carries its own "Chapter Progress" table for a chapter-scoped view — this file is the whole-project view. ## How priority was assigned

Priority is not a claim about which question matters more spiritually — it is a research-sequencing judgment: P0 questions are the ones whose answers condition how several other questions should be read (e.g. resolving how much evidentiary weight "recorded in Sahih Muslim" should carry, per `METHODOLOGY.md`, changes how every other hadith-based question in this project should be approached), or that go to the root of a major doctrinal pillar (Qur'an integrity, who counts as Ahl al-Bayt, the legitimacy of the Imamate), or — new in this pass — are the concrete test case for one of the four Methodology principles (§2.1, §3.2, §6.6). P1 covers major supporting pillars. P2 covers specific case studies that illustrate or support a P0/P1 question. P3 is reserved for items the source material itself left too vague to research yet. This ordering is a starting recommendation, not a constraint — work whatever question is most useful next.
