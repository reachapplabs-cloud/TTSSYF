Notifications · Manual
  • Compose: title, body, optional image, optional deep link (product / category / seller / in-app screen).
  • Send now, or schedule for later.
  • Segments: all buyers · location/region · seller/category history · cart/wishlist no purchase · new signups · inactive.
  • Send history/log; daily send cap; respect opt-out; no off-hours sends.
Notifications · Automated (core 4)
  • Order status change — placed / shipped / out for delivery / delivered / cancelled / refund → buyer on that order.
  • Abandoned cart — item(s) left in cart, no checkout after X hours → that buyer.
  • Wishlist-to-cart follow-through — wishlisted item moved to cart, never purchased after X hours → that buyer.
  • Back-in-stock — wishlisted/out-of-stock item becomes available → buyers who wishlisted it.
  • Admin trigger config: per-trigger on/off, message template with variables ({item_name}, {order_id}), condition tuning (e.g. the "X hours" threshold).
  • One unified send history/log for manual + automated together.
  • Guardrails: combined daily cap across manual + automated per buyer; dedup/priority when triggers overlap (order-status wins over cart nudges).
